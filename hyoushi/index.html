STEP1

ChatGPTとCanvaをつなぐ

目安 5分　｜　使うもの：ChatGPTとCanvaのアカウント
  1. ChatGPTを開く（動画ではパソコンでやりましたが、スマホでもできます）
  2. 左上の「プラグイン」を開く
    見つからないときは、左下の自分のアカウント →「設定」の中にある「プラグイン」から
  3. 一覧から「Canva」を選んで、「プラグインをインストール」を押す
    一覧にないときは「プラグインを検索」で「canva」と入れる
  4. Canvaのログイン画面が出たら、いつも使っているCanvaのアカウントでログインする
  5. 「許可」を押して、完了の表示が出たらOK

ChatGPTもCanvaも、Googleアカウントがあればすぐに始められます。

このページだけつまずいたときは

  • Canvaが出てこない：ChatGPTを一度閉じて、開き直してみてください。それでも出てこないときは、プラグインの画面でCanvaの接続を解除して、もう一度つなぎ直します
  • 途中で止まって、デザインが出てこない：無料プランだと止まることがあります。少し時間をおいてから、同じプロンプトをもう一度送ってみてください
  • お願いするときは、最初に「Canvaで」と書く：プロンプトの1行目に入れておくと、Canvaで作ってほしいことが伝わります
STEP2

プロンプト①　Kindleの表紙

目安 15分　｜　使うもの：Canvaをつないだ ChatGPT

このページだけ2-A　依頼主さんに、先に聞くこと7つ

  • 本のタイトル
  • サブタイトルやキャッチコピー（あれば）
  • 表紙にのせる著者名
  • どんな本か（ジャンルと、中身をひと言で）
  • 読んでほしい人
  • 好きな雰囲気や、使いたい色
  • 「こんな感じがいい」という見本の表紙（あれば画像で）

ここがあいまいなまま作り始めると、何度も作り直すことになります。先に聞いておくだけで、1回目からイメージに近いものが出やすくなりますよ。

依頼主さんへの確認メッセージの見本
このたびはご依頼ありがとうございます。
表紙を作り始める前に、いくつか教えてください。

1. 本のタイトル
2. サブタイトルやキャッチコピー（あれば）
3. 表紙にのせる著者名
4. どんな本か（ジャンルと、中身をひと言で）
5. 読んでほしい方
6. お好きな雰囲気や、使いたい色
7. イメージに近い表紙があれば、画像を送っていただけるとうれしいです

分からないところは空けたままで大丈夫です。
いただいた内容をもとに、まず何パターンかお作りしますね。

ちゃんと自分の言葉で書いてほしいのですが、書き方の見本として活用してくださいね。

2-B表紙を作るプロンプト

STEP1でCanvaをつないだ ChatGPT に送る
プロンプト①　Kindleの表紙
Canvaで、Kindle本（電子書籍）の表紙を作ってください。

【サイズ】縦長の 幅1600×高さ2560ピクセル
【タイトル】在宅ワークの始め方
【キャッチコピー】おうちで、自分らしく働こう（タイトルの上に短く）
【著者名】〇〇〇〇（タイトルの下に小さめに）
【雰囲気】窓から朝の光が入る部屋に、ノートパソコンとコーヒーカップが置かれた、やわらかい雰囲気
【パターン】「ナチュラル」「明るくポップ」「落ち着いた上品さ」の3パターン

・タイトルは、スマホの一覧で小さく表示されても読めるように、大きく太い文字にしてください
・文字が背景に埋もれないように、はっきり読める色にしてください
  1. 【　】のあとを、依頼主さんから聞いた内容に書きかえて送る
  2. 見本の表紙をもらっているときは、その画像も一緒に送って、プロンプトの最後に下の1行を足す
  3. 気に入った案の「Edit in Canva」を押して、Canvaで文字を整える
見本の画像があるときに足す1行
添付した画像の雰囲気に近づけてください。

動画で使ったプロンプトに、読みやすさのお願いを2行足してあります。

私、デザインのことは何もしていないんです。やったのは、言葉でお願いしただけ。それでも、ここまで作れちゃうんです。

このページだけ2-C　渡す前の仕上げチェック

  • 画面を小さくして、切手くらいの大きさでもタイトルが読めるか確かめる。読めなければ、「ちょっと大きすぎるかな？」くらいまで大きくする
  • 強調したい言葉だけ色を変えて、メリハリをつける
  • タイトル・キャッチコピー・著者名を、依頼主さんからもらった文字と1文字ずつ見比べる
  • 実在の人の顔、お店や会社のロゴ、ほかの本の表紙にそっくりな部分があれば、作り直してもらう
  • 依頼主さんに言われたサイズで、「共有」→「ダウンロード」から保存する（指定がなければJPGで。Kindleの表紙はJPEGかTIFFで受け付けています）

Kindleの表紙は、スマホで見ると切手くらいの小さなサイズで並びます。小さくしたときに目に留まって読めるかが、いちばん大事なところです。

STEP3

プロンプト②　動画の台本

ショートも長尺もOK　｜　目安 ショートなら15分　｜　使うもの：ChatGPT・Gemini・Claude のどれか

3-AAIに伝える4つを、くっきり書く

ふんわりくっきり
誰に女性向け在宅ワークに興味がある、20〜30代の会社員の女性
何の話在宅ワークの話スマホだけで始められる在宅ワーク
どの順番おまかせ最初の一言で興味を引く → 理由 → 具体例 → 最後のひと言
どんな話し方明るく友達に話すような、やわらかい話し言葉
このページだけ｜迷ったら、ここまで書く

「ふんわり」のままだと、誰に向けたのか分からない、AIっぽい文章が出てきます。「誰に」で迷ったら、「その人は何歳くらいで、毎日どんなふうに過ごしている人？」まで書いてみてください。

3-B台本を作るプロンプト

ChatGPT・Gemini・Claude、どれでもOK
プロンプト②　動画の台本
YouTube動画の台本を書いてください。

【動画の種類】ショート動画（縦型）
【長さ】60秒・約300文字
【誰に】在宅ワークに興味がある20〜30代の会社員の女性
【何の話】スマホだけで始められる在宅ワーク
【順番】最初の一言で興味を引く → 理由 → 具体例 → 最後のひと言
【話し方】友達に話すような、やわらかい話し言葉

・数字・サービス名・人の名前など、あとで調べて確かめたほうがいいところには【確認】と印をつけてください
・声に出して読んだときに、言いにくい言い回しは使わないでください
・【動画の種類】が長尺動画（横型）のときは、いきなり全文を書かずに、先に見出し（目次）と、見出しごとの長さの目安だけを出してください。私がOKしたら、見出しを1つずつ本文にしてください
  1. 【　】のあとを、依頼主さんの動画に合わせて書きかえる
  2. 長い横型の動画（長尺）のときは、下の表のとおり【動画の種類】【長さ】【順番】を書きかえる
  3. 長尺のときは、見出しが出てきたら、うなずけるか確かめて「OK」と返す。直したいところがあれば先に伝える
  4. 出てきた台本を、下の3-Dのチェックで仕上げる

このページだけショートと長尺で、書きかえるところ

ショート（縦型）長尺（横型）
動画の種類ショート動画（縦型）長尺動画（横型）
長さ60秒・約300文字15分・約4,500文字
話す速さは1分で約300文字が目安
順番最初の一言で興味を引く → 理由 → 具体例 → 最後のひと言この動画で分かること → 本編を3つに分けて説明 → まとめと、次にやること

長尺の台本を一度に全部書いてもらうと、途中で話が重なったり、後半が薄くなったりしがちです。見出しを先に決めてから1つずつ書いてもらうと、話の流れがぶれません。

このページだけ3-C　台本の依頼主さんに、先に聞くこと

  • 上の4つ（誰に／何の話／どの順番／どんな話し方）
  • 動画の種類と長さ（ショートか長尺か、何分・何文字くらいか）
  • いつも使っている言い回しや口ぐせ
  • 使ってほしくない言葉
  • これまでの動画のリンク（話し方の参考にする）

このページだけ3-D　渡す前の仕上げチェック

AIの文章は、そのまま渡さないでください。必ず最終チェックと付け足しをしてから納品しましょう。

  • 【確認】の印がついた数字や名前を、自分で調べて確かめる
  • 声に出して読んで、言いにくいところを言いやすい言葉に直す
  • 依頼主さんがいつも使っている言い回しに寄せる
  • 依頼主さんの体験やエピソードが入れられるところに、一言付け足す
  • 最後に【確認】の印を消して、きれいな状態で渡す

私もインスタの発信を1年以上続けていて、リールの台本はAIと一緒に作っています。AIの文章はとても自然ですが、間違った数字や古い情報がまぎれていることもあるので、最後の仕上げだけは人の目が必要なんですよね。

STEP4

出品より先に、見本をつくる

目安 1日1枚ずつ　｜　使うもの：STEP2とSTEP3のプロンプト

動画でもお話ししたとおり、出品したからといって、すぐに依頼が来るわけではありません。なので最初にやってほしいのは、出品より先に、見本を作ることです。

このページだけ4-A　見本用のタイトル案を出してもらう

「好きな本のタイトルを考えて」と言われても、意外と手が止まるんですよね。そんなときは、AIに題材から出してもらいましょう。

見本用のタイトル案を5つ
Kindle本の表紙の見本（ポートフォリオ）を作る練習をしています。
実在しない本のタイトル案を、ジャンルを変えて5つ出してください。

・ジャンルの例：お金、暮らし、料理、仕事、健康、趣味
・それぞれに、短いキャッチコピーと、表紙の雰囲気（色や写真のイメージ）を1行ずつ付けてください
・すでに出版されている本と、同じタイトルにならないようにしてください

出てきたタイトル案を、STEP2のプロンプトの【　】に入れて作ります。ポートフォリオは、「私はこんなものが作れます」と見せるための作品集のことです。

4-B見本のチェックリスト

  • 表紙を3〜5枚。ジャンルと雰囲気を変えて作る
  • 動画の台本も2〜3本。まずは短いショートから、STEP3のプロンプトで自分の好きなテーマで書いてみる
  • スマホのアルバムに「見本」のフォルダを作って、まとめておく
  • 著者名は、実在の人の名前を使わず「〇〇〇〇」や架空の名前にする

この見本が、そのまま「私、こんな表紙が作れます」という名刺代わりになってくれます。

まずは、この3つから

今日やるのは、ここまでで十分です

  • ChatGPTとCanvaをつなぐ
  • STEP4のプロンプトでタイトル案を出して、表紙を1枚作る
  • 自分の好きなテーマで、動画の台本を1本作る（まずはショートで）

「AIにお願いしたら、本当に形になった」を一度体験すると、次の1枚がぐっと楽になりますよ。

受け取ってくれたあなたへ

ここまでやっても、たぶん残るもの

このページで、表紙と台本を「作れる」ところまでは進めます。でも正直にお伝えすると、見本ができても、すぐに依頼が来るとは限りません。それに、表紙も台本も、自分が手を動かした分だけの収入になる働き方なんですよね。

動画の3つ目でお話ししたように、自分のインスタのリールは、投稿したあとも残り続けて、コツコツ収入を運んでくれます。ただ、そこできっと、こんなところで迷うと思います。

  • 自分のインスタでは、どんなリールを作ればいいんだろう
  • 私に合うジャンルって、何だろう
  • AIでリールを作っても、見てもらえなかったらどうしよう
  • 本業をしながら、どのくらいのペースで続ければいいの？

ここは、その人の好きなことや生活のリズムによって答えが変わるので、このページには書ききれませんでした。

私も在宅ワークを始めたころは、手紙の代筆で時給400円くらいでした。インスタを始めてからも、オリジナルのやり方は何もなくて、教わったコツを1つずつそのままやっていっただけなんです。

こうして特典を受け取っていただいた出会いも、私は大事な“縁”だと思っています。「自分の場合は、どんなリールから始めたらいいんだろう」と感じた方は、1対1の無料個別相談会に来てみてください。

相談会では、あなたの今の状況や、好きなこと・得意なことをお聞きしながら、あなたに合ったジャンルや、どんなリールを投稿していくといいかを一緒に考えます。AIの使い方や考え方についても、初心者さんに分かりやすくお話ししますね。（参加者限定の豪華8大プレゼントもあります）

  • 実績なしでも始められる
  • 年齢制限なし
  • 完全在宅、スマホ1台でできる
  • 本業をしながら、スキマ時間で進められる
